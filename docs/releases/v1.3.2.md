# Spine Shelf v1.3.2

在角色的「资源信息 → AI 换肤」中填写要求，点击「开始制作」即可直接调用本机 Codex。完成后，新皮肤加入同一角色，可在皮肤列表切换。

## 本次更新

- **直接制作**：复用本机 Codex 的 ChatGPT 登录，自动连接当前任务的 MCP，支持取消和失败后重试。
- **同一角色换肤**：保留骨骼、动画与原皮肤；新增皮肤后自动刷新预览和缩略图。
- **制作详情**：查看 Codex 的阶段说明，切换「主要进度 / 全部操作」，查看工具状态、耗时与错误。记录保存后可继续查看；旧记录缺少时间时标为「此前」。
- **进度修复**：普通工具事件不再覆盖具体说明，显示已用时间与最近更新时间，不估算完成百分比。
- **兼容性修复**：支持 Spine 3.8.75 JSON 的本地预览，保留版本与原始数据；该版本的二进制 SKEL 仍需重新导出。

## 下载

| 系统 | 安装包 |
| --- | --- |
| Windows 11 · Intel / AMD | `Spine-Shelf-1.3.2-Windows-x64-Setup.exe` |
| Windows 11 · ARM | `Spine-Shelf-1.3.2-Windows-arm64-Setup.exe` |
| macOS · Apple Silicon | `Spine-Shelf-1.3.2-macOS-arm64.dmg` |

`SHA256SUMS.txt` 提供安装包校验值。Windows 双击安装，macOS 打开 DMG 后拖入「应用程序」。安装包未代码签名或 Apple 公证，与先前版本一致。

## 使用与升级

已有资源库可继续使用。AI 换肤需要本机安装新版 Codex、使用 ChatGPT 账号登录并能访问图片生成能力；制作期间保持 Spine Shelf 打开。软件可以使用已安装的 `spine-reskin` 技能指导部件制作。

新皮肤保存在资源库的扩展数据中，**尚未合并导出到原 JSON/SKEL**。迁移与备份请退出应用后复制整个 `Library` 文件夹；仅复制原三件套不包含新增皮肤。任务记录也随资源库保存。

## 验证范围

macOS Apple Silicon 已完成真实 Codex 图片生成、MCP 写回和同角色皮肤切换验证。自动化覆盖任务启动、取消、重试、进度记录与旧记录读取，以及 Spine 3.8 / 4.0 / 4.1 / 4.2 / 4.3 的 JSON/SKEL 换肤。

发布工作流在 macOS、Windows x64 与 Windows ARM64 构建并检查安装包。Windows 真实 Codex 图片生成流程尚未验证，能否直接制作取决于本机 Codex 可执行文件和登录状态。
