# Spine Shelf v1.0.0

首个公开版本：把 Spine 动画整理成一个能长期保存、分类和预览的本地素材库。

## 下载

- **macOS Apple Silicon（M 系列）**：下载 `Spine Shelf-1.0.0-arm64.dmg`，打开后拖入「应用程序」。
- `SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。
- Windows / Intel Mac 暂无本次验证的安装包。

## 功能

- 批量导入文件夹，递归识别 JSON / SKEL、ATLAS 和贴图，自动去重并保存完整副本。
- 人物、场景、普通素材和待分类；本地规则识别，可手动修正。
- 收藏、分组、标签、备注、搜索和网格/列表浏览。
- 预览 Spine 3.8、4.0、4.1、4.2、4.3，支持切换动画与皮肤、调速、循环、时间轴、缩放、平移、翻转和骨骼显示。
- 导出透明 PNG，拖动调整预览宽度，悬停查看按钮说明。
- 新的骨骼关节与播放三角形 Logo。

## 已知限制

- `.spine` 编辑器工程需先导出；暂不支持 ZIP、加密资源及游戏专有压缩纹理。
- 自动分类依赖素材内部命名，不是视觉 AI；线索不足时归入待分类。
- 安装包尚未经过 Apple Developer ID 签名或公证。macOS 阻止首次打开时，可在「系统设置 → 隐私与安全性」允许打开。
