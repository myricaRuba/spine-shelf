# Spine Shelf v1.1.0

新增 Windows 11 桌面版，保留文件夹导入、自动分类、持久资源库和完整动画预览。

## 下载

- **Windows 11 · Intel / AMD 电脑**：`Spine-Shelf-1.1.0-Windows-x64-Setup.exe`
- **Windows 11 · ARM 电脑（如 Snapdragon）**：`Spine-Shelf-1.1.0-Windows-arm64-Setup.exe`
- **macOS · Apple Silicon（M 系列）**：`Spine-Shelf-1.1.0-macOS-arm64.dmg`
- `SHA256SUMS.txt`：安装包的 SHA-256 校验值。

Windows 双击 EXE 安装，可选择安装目录，默认安装给当前用户。通过桌面或开始菜单打开应用，导入文件夹即可使用。无需安装 Node.js 或其他开发工具。

## 本次更新

- Windows 原生最小化、最大化、关闭按钮；标题栏为系统按钮预留空间。
- Ctrl + O 导入、Ctrl + K 搜索；从设置中打开 Windows 文件资源管理器。
- 多尺寸 ICO 应用图标，覆盖任务栏和不同缩放比例。
- Windows 自动化验证安装、重装、卸载、资源库保留、中文路径导入、实际动画像素渲染及重启持久化。
- Windows 上验证 Spine 3.8、4.0、4.1、4.2、4.3 的 JSON / SKEL 预览。
- GitHub Actions 构建三个平台的安装包与校验文件。

## 数据与升级

Windows 资源库在 `%APPDATA%\Spine Shelf\Library\`，macOS 位置不变。安装目录与素材目录分离，Windows 卸载保留资源库。退出应用后复制整个 `Library` 文件夹可进行备份或跨系统迁移。v1.0.0 用户可直接安装新版，资源库格式保持兼容。

## 验证与限制

Windows x64 在 Windows Server 2025 上自动验证，ARM64 在 Windows 11 上自动验证；macOS 在 Apple Silicon 上验证。尚未逐一测试普通 Intel / AMD Windows 11 实机的显卡和缩放组合。

安装包未代码签名：Windows 可能显示未知发布者或 SmartScreen 提示；macOS 未经 Developer ID 签名或公证。请核对本仓库来源及校验值。

`.spine` 编辑器工程需先导出；ZIP、加密素材和专有压缩纹理暂不支持。自动分类使用本地命名与骨骼规则，不是视觉 AI。
