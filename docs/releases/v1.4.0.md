# Spine Shelf v1.4.0

新增游戏项目：从资源库批量挑选素材，按人物、地形、道具、特效、界面等分类整理，也可以新增自己的分类。同一素材可用于多个项目，分别设置项目内名称、用途备注和导出皮肤。

整理好后，点击「导出项目」生成 ZIP 通用素材包。包内按分类保存骨骼、图集和贴图，附 JSON/CSV 资源清单、使用说明与 SHA-256 校验。移出素材或删除项目会保留资源库中的素材。

每份素材导出选中的一套外观；AI 皮肤固化到导出贴图中，原骨骼与动画不变，清单提供实际运行时皮肤名。此包用于导入游戏工程，不含场景或脚本，也不合并所有 AI 皮肤到同一骨骼。

支持旧资源库自动补充项目字段，保留已有素材、收藏、分组及换肤结果。更新前可退出软件备份整个 `Library` 文件夹。

## 下载

| 系统 | 安装包 |
| --- | --- |
| Windows 11 · Intel / AMD | `Spine-Shelf-1.4.0-Windows-x64-Setup.exe` |
| Windows 11 · ARM | `Spine-Shelf-1.4.0-Windows-arm64-Setup.exe` |
| macOS · Apple Silicon | `Spine-Shelf-1.4.0-macOS-arm64.dmg` |

`SHA256SUMS.txt` 提供三个安装包的校验值。Windows 双击安装，macOS 打开 DMG 后拖入「应用程序」。安装包未代码签名或 Apple 公证，与先前版本一致。

## 使用

左侧「游戏项目 → +」创建项目，点击「添加素材」批量选择，设置分类和皮肤后点击「导出项目」。资源信息里也可以将当前素材加入项目。包内的 `使用说明.txt` 说明目录结构、运行时皮肤名和版本匹配要求。

项目导出不转换 Spine 版本，需使用匹配的游戏运行库。AI 换肤继续沿用本机 Codex 与 MCP 的原有流程。

## 验证范围

自动化覆盖旧库迁移、跨项目独立设置、分类、同名路径、ZIP 清单与文件校验、失败时保留原文件。桌面测试从安装包创建项目、导出、解压重导入，对比相同动画帧的像素并检查重启持久化。

发布工作流在 macOS Apple Silicon、Windows Server 2025 x64 和 Windows 11 ARM64 构建并测试安装包。Windows 真实 Codex 图片生成流程尚未验证，与 v1.3.2 相同。
